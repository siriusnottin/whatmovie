# What Movie?

Watchlist for your movies and TV Shows.

## Project stack

PHP, Apache, MariaDB, Docker, TailwindCSS, Sass.

## How to use?

```bash
docker compose up --build -d
```

## How to access?

- [http://localhost:8080](http://localhost:8080)
